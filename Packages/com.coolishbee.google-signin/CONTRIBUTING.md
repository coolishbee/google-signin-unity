# Contributing

Submit changes through pull requests. For larger changes, open an issue first to explain the goal and scope. When modifying sign-in behavior, include platform-specific results and identify any validation you could not perform.

Move `.meta` files together with package and sample assets to preserve GUIDs. When changing the sample, keep `Samples~/SignInSample/` and `SampleProject/Assets/SignInSample/` in sync.

## Upstream contribution policy

The original Google project requires the [Individual Contributor License Agreement](https://developers.google.com/open-source/cla/individual?csw=1) before merging contributions; corporate contributions use a separate agreement. Follow those requirements when submitting changes upstream. This statement does not introduce a separate agreement process for this fork.
